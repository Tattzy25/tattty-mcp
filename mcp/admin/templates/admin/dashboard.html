        Server instructions

        Everything you need to configure, run, and share this MCP-over-HTTP service.

        1. Install dependencies. 
          pip install -r requirements.txt

          The project targets Python 3.12+. The command above brings in FastAPI, SlowAPI, httpx, Pillow, and other tool deps.

        2. Copy secrets into .env.

          Duplicate .env.example → .env and fill the keys below:

          • STABILITY_API_KEY – required for every Stability tool (sd3.5, background edit, control suite).
          • GROQ_API_KEY – unlocks the groq_chat MCP tool.
          • MCP_ADMIN_TOKEN – protects this dashboard (plus optional query ?token= sharing).
        3. Launch the server. 
          uvicorn mcp.server:app --host 0.0.0.0 --port 8000

          Override host/port through mcp/config.yaml or env overrides like MCP_PORT.

        4. Call tools via HTTP. 
          curl -X POST http://localhost:8000/mcp/stability_sd35_generate \
  -H "Content-Type: application/json" \
  -d '{"prompt":"sunrise city","model":"sd3.5-large"}'

          Every MCP tool lives under /mcp/<tool_name> and returns JSON with status, tool, and the tool payload.

        5. Secure + share.

          Flip Allow anonymous off to enforce bearer tokens, set a rate limit, then tunnel (ngrok, Cloudflare) or deploy via Docker/Railway.
