        Server Instructions

        End-to-end setup walkthrough.

        1. Install dependencies: 
          pip install -r requirements.txt
        2. Configure secrets:

          Copy .env.example → .env and fill STABILITY_API_KEY, GROQ_API_KEY, MCP_ADMIN_TOKEN.

        3. Launch server: 
          uvicorn mcp.server:app --host 0.0.0.0 --port 8000
        4. Test a tool: 
          curl -X POST http://localhost:8000/mcp/stability_sd35_generate \
  -H "Content-Type: application/json" \
  -d '{"prompt":"sunrise city","model":"sd3.5-large"}'
        5. Secure + share:

          Disable anonymous mode, set rate limits, tunnel via ngrok/Cloudflare, or deploy to Railway.
